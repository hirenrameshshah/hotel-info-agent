

# Hotel Info Agent

## Project Overview
Hotel Info Agent is an AI-powered assistant designed to answer guest questions using only approved hotel information. It helps guests quickly get accurate responses about hotel services, policies, amenities, and local guidance while avoiding unsupported or unsafe answers.
